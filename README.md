# 寶雅派駐人員 薪資・差勤查詢系統

和排班網站完全分開的獨立網站：自己的 GitHub 儲存庫、自己的 Apps Script 專案、自己的 Google 試算表、自己的網址。

| 部分 | 檔案 | 放哪裡 |
|---|---|---|
| 網頁前端 | `index.html`、`app.js`、`parser.js`、`config.js`（根目錄） | 新的 GitHub 儲存庫（GitHub Pages） |
| 後端程式 | `backend/Code.gs` | 新的 Apps Script 專案 |
| 資料庫 | 執行 `setup()` 時自動建立「寶雅薪資差勤資料庫」試算表 | 你的 Google 雲端硬碟 |

網站上沒有任何薪資資料，資料只存在你的試算表裡，所以 GitHub 儲存庫可以是公開的。

## 一、建立後端（Apps Script）

1. 到 script.google.com →「新專案」，命名為「寶雅薪資差勤系統」。
2. 把 `backend/Code.gs` 的內容整個貼上，取代原本的程式碼，存檔。
3. 上方函式選單選 `setup` →「執行」，依畫面完成授權。
4. 打開「執行紀錄」，會看到：
   - 管理員帳號 `admin` 和一組初始密碼（第一次登入後會要求改密碼）
   - 想改管理員帳號名稱，直接改試算表「管理員」分頁的「帳號」欄（目前為 `ts983118`）
   - 資料庫試算表的網址
5. 「部署」→「新增部署作業」→ 類型選「網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 複製部署出來的網址（結尾是 `/exec`）。

忘記管理員密碼：在編輯器執行 `resetAdminPassword`，會重設「管理員」分頁第一個帳號，新密碼印在執行紀錄。

## 二、建立前端（GitHub Pages）

1. 在 GitHub 建一個新的儲存庫，例如 `baoya-payroll`。
2. 把 `frontend` 資料夾裡的 4 個檔案上傳到儲存庫根目錄。
3. 編輯 `config.js`，把第一步複製的網址貼到 `API_URL: ''` 的引號中。
4. 儲存庫 Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save。約 1～2 分鐘後就有網址。

- 網址：`https://<帳號>.github.io/baoya-payroll/`（員工和管理員用同一個網址登入；帳號是員編或 TC 編號的就當員工，其他帳號當管理員）

## 三、每月操作

1. 用管理員帳號登入 →「上傳附表」。
2. 選擇 `寶雅-承攬派遣附表-長期.xlsx`：系統會讀
   - 「請款明細-寶雅」→ 每人薪資單（本薪、伙食、加班費、津貼、請假扣薪、福委、個人負擔、實領）
   - 「勞健保扣項」→ 個人負擔明細（勞保／就保／健保／勞退自提）
   - 「月.時薪統整」→ 出勤時數彙總（當月工時、各段加班、各類請假時數）
   - 「長期月薪」「長期時薪」→ 每日出勤（班別、上下班時間、工時、加班、請假、夜班津貼）
   - 「特休」→ 到職日、年資、累計已休、剩餘特休
   - 長期月薪／長期時薪自動判斷：請款明細有「時數」的是時薪，沒有的是月薪。
3. 選擇 `寶雅-承攬派遣附表-支援.xlsx`（PT）：讀「請款明細-支援」（薪資）、「保費差額」（個人負擔明細）、「出勤工時」（工時與加班）。
4. 畫面會顯示人數、實領合計和檢查結果。系統會逐人核對「加項－扣項＝應付薪資」「應付－個人負擔＝實領」，對不上的會列出來；點任一列可以先看該員工看到的畫面。
5. 按「上傳到系統」。這時員工還看不到。
6. 到「月份與發布」按「發布」，員工登入後就能看到這個月份。

**期間代碼**：系統從請款明細第 2 列的起訖日自動帶出，例如 `115-10`；PT 半月附表會變成 `115-08A`（上半月）、`115-08B`（下半月）。同一個代碼重新上傳會整批覆蓋，並改回「未發布」。

**實領與實付不同時**：附表裡「派遣人員實領」和「日城實付薪資」有差額的人，員工的薪資單會顯示「本月實際匯款 X 元，差額 Y 元另行補發或補扣」。

## 四、開通員工帳號（密碼固定為身分證字號）

- 後台「員工帳號」→「匯入員工資料（日城）」，選 `員工資料日城.xlsx`：
  - 讀第一個工作表的「員工代號」「員工姓名」「身份證字號」「組織名稱」「身分別」。
  - 只匯入「組織名稱」含「寶雅」的人（寶雅-長期人員、寶雅-支援），「身分別」為離職的略過。
  - 密碼設為身分證字號（英文字母大小寫都可），試算表只存加鹽雜湊，不存身分證字號。
- 員工不能自行改密碼（後端 `APP.FIXED_PASSWORD = true`）。要恢復「員工自行改密碼」，把它改成 `false` 並重新部署。
- 個別補設或重設：後台「員工帳號」→「重設密碼」，輸入身分證字號。
- 離職人員：按「停用」。

## 五、請假（長期月薪）

- 只有「類別」為長期月薪的員工，登入後會多一個「請假」分頁：看假別額度、線上申請、取消審核中的申請。
- 額度計算：
  - **特休：週年制**，依到職日（取自長期附表「特休」分頁）按勞基法第 38 條給天數，期間為每個到職週年日起算一年。
  - **事假、病假、生理假等：曆年制**（1/1～12/31）。事假 14 天、病假 30 天；家庭照顧假併入事假。
  - **生理假**（性別平等工作法第 14 條）：每月 1 日；全年前 3 日不併入病假，超過的併入病假 30 日計算；病假請滿 30 日後仍須給假（超過部分可不支薪），系統會提醒但不阻擋。
  - 額度換算：1 天 = 各人的工作時數，一般月薪人員 10 小時（事假 140、病假 300、特休 天數×10），張銘峰 8 小時。
  - 已休 = 已上傳出勤明細裡的請假時數 ＋ 已核准的申請（同一天同假別不重複計算）＋ 試算表「請假調整」分頁的期初時數。
- 超過額度：事假、病假、家庭照顧假超過全年天數時**只提醒、不阻擋**，員工仍可送出，審核頁會標「⚠ 超過額度」由人事決定；特休超過週年額度、生理假每月超過 1 日則不能送出。
- 請假方式可選「整天」或「按時數」：整天時 1 天 = 10 小時（`APP.WORKDAY_HOURS`），張銘峰 1 天 = 8 小時（`APP.WORKDAY_HOURS_BY_EMP`）。
- 請假以每日起訖時間申請，只能選整點或半點（例 08:30–09:00 = 0.5 小時），時數 = 結束 − 開始，不扣午休與休息。
- 病假必須上傳證明（照片或 PDF），存在雲端硬碟「寶雅請假證明」資料夾；特休、事假不用填理由。第一次使用前在編輯器執行 `authorizeDrive` 授權雲端硬碟。
- 審核中的申請員工可以自行修改或取消；管理員可修改審核中與已核准申請的假別、日期、時間，修改紀錄保留在「修改紀錄」欄。
- 管理員「請假審核」分頁：核准、駁回、撤銷已核准的申請；點姓名可看該員工的額度。
- 系統上線前已請的假：在試算表「請假調整」分頁填「東慧員編、假別、適用起日、已休時數、說明」。

## 六、報加班

- 名單在後端 `APP.OVERTIME_EMP`（東慧員編），目前是張銘峰（164580）。名單內的員工登入後多一個「報加班」分頁：填日期、類別（平日／休息日／國定假日／例假日）、起訖時間、扣休息時數、事由。
- 系統依勞基法第 24 條拆出倍率時數（平日前 2 小時 ×1.34、之後 ×1.67；休息日 1–2 ×1.34、3–8 ×1.67、9–12 ×2.67；國定假日／例假日 8 小時內加倍）。
- 每月加班超過 46 小時只提醒、不阻擋。管理員在「加班審核」分頁核准、駁回或撤銷。

## 七、安全

- 密碼加鹽雜湊儲存，連續輸錯 5 次鎖 15 分鐘，登入 6 小時後自動登出。
- 資料庫試算表請勿分享給其他人；Apps Script 以你的身分讀寫它。
- 「紀錄」分頁有登入、上傳、發布、改密碼紀錄。
- 員工只看得到自己的、而且已發布的月份。
